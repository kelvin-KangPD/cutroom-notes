ปุ่ม X ของ AULA F108 Pro กดไม่ติด ผมเลยหยิบหัวแร้งขึ้นมา แล้วเจอทั้งไฟช็อตและแพดที่หลุด สุดท้ายซ่อมได้ด้วยการทดสอบข้อสันนิษฐานของ Claude ทีละข้อและเดินสายไฟไปที่แพดของปุ่มข้าง ๆ

🙋🏻‍♂️ บัดกรีคีย์บอร์ดเหรอ ได้ยินว่าแค่แตะหัวแร้งนิดเดียวก็จบ 🙋🏻‍♀️ ผมก็คิดแบบนั้นเหมือนกัน ฮ่า ๆ

![คีย์บอร์ด AULA F108 ก่อนแกะ มีปุ่มสีเทาและลูกบิดที่มุมขวาบน](/images/20261102-aula-f108-keyboard-repair/01-분해-전-독거미-F108.webp)
<small>F108 Pro ก่อนแกะ ตอนที่ยังคิดว่าแค่ซ่อมปุ่ม X ปุ่มเดียวก็จบ</small>

สุดสัปดาห์หนึ่งผมนั่งเล่นคีย์บอร์ดไปพร้อมกับคุยกับ Claude แล้วภรรยาก็พูดขึ้นมาจากข้าง ๆ ว่า "พิมพ์แรงไปหรือเปล่า" 🤔

ผมบอกว่าจะพิมพ์เบา ๆ แต่คำนั้นก็ค้างอยู่ในใจ แล้วผมก็เห็นคีย์บอร์ดสวย ๆ ขายถูกผ่านบริการส่งตรงจากต่างประเทศของ Coupang เลยกดซื้อทันที ถึงตรงนี้ก็ยังเป็นเรื่องช็อปปิ้งธรรมดา 😛

โพสต์นี้คือบันทึกการซ่อมที่เริ่มจากปุ่ม X ของคีย์บอร์ดตัวนั้น เป็นครั้งแรกที่ผมบัดกรี และไม่มีมัลติมิเตอร์ด้วย **แล้วทำไมผมถึงไม่ยอมแพ้กลางทาง**

> **เป้าหมาย** ทำให้ปุ่ม X ที่เสียกลับมาใช้ได้<br>
> **อุปสรรค** แพดหลุดระหว่างบัดกรี ไฟช็อตที่ทำให้สองแถวกดพร้อมกัน ไม่มีเครื่องมือวัด<br>
> **ผลลัพธ์** แก้ไฟช็อตได้ ปุ่ม X กลับมาใช้ได้ด้วยการเดินสายอ้อมไปที่แพดของปุ่มข้าง ๆ

## กล่องที่หนึ่ง📦 คีย์บอร์ดเสียงดังกับปุ่ม X ที่กดไม่ติด

![หน้ารีวิว Coupang ที่มีรีวิวห้าดาวของ AULA F108 Pro 104 ปุ่ม สวิตช์ Caramel Latte](/images/20261102-aula-f108-keyboard-repair/02-쿠팡-리뷰.webp)
<small>AULA F108 Pro Caramel Latte ที่ซื้อจาก Coupang และรีวิวที่เขียนด้วยระบบอัตโนมัติของ Claude</small>

รุ่นที่ซื้อคือ AULA F108 Pro 104 ปุ่ม สวิตช์ Caramel Latte รีวิวก็เขียนด้วยระบบอัตโนมัติของ Claude ผมแค่โยนคีย์เวิร์ดไปไม่กี่คำ Claude ก็เขียนรีวิวและกดปุ่มส่งให้เลย แต่พอของมาถึงแล้วลองพิมพ์ไม่กี่คำ เสียงดังกว่าที่คิด 😫

บังเอิญที่บ้านมีสวิตช์ Peach ว่างอยู่ คีย์บอร์ดตัวนี้เป็นแบบ hot-swap ถอดสวิตช์เปลี่ยนได้ ผมเลยเปลี่ยนทั้งหมด 👀**<mark>ซื้อคีย์บอร์ดมาเพื่อให้เงียบลง แต่ปัญหาจริงเริ่มขึ้นตอนเปลี่ยนสวิตช์นี่เอง</mark>**

![คีย์บอร์ดที่ถอดปุ่มออก มีสวิตช์ Peach สีชมพูเสียบอยู่เป็นจุด ๆ](/images/20261102-aula-f108-keyboard-repair/03-피치축-교체.webp)
<small>F108 Pro ระหว่างเปลี่ยนสวิตช์ ถอดของเดิมออกแล้วใส่สวิตช์ Peach ที่มีอยู่</small>

พอทดสอบ X ไม่ติด ผมลองเปลี่ยนสวิตช์ตัวอื่นและลองอีกหลายอย่างก็ไม่ดีขึ้น ค้นใน Naver เจอโพสต์ที่บอกว่าแค่เปิดบอร์ดด้านหลังแล้วแตะหัวแร้งเบา ๆ ก็จบ ผมทำตาม[โพสต์ซ่อมปุ่ม AULA F99 กดไม่ติด](https://blog.naver.com/ststeel/224044004123) และรู้จากโพสต์นั้นด้วยว่าต้องถอดแบตเตอรี่ทุกครั้งที่เปิดฝาล่าง 🤩

![หัวแร้งและตะกั่วม้วนจาก Daiso ยังอยู่ในแพ็กเกจ](/images/20261102-aula-f108-keyboard-repair/04-다이소-인두기와-납.webp)
<small>หัวแร้งและตะกั่วที่แวะซื้อที่ Daiso ระหว่างทางกลับบ้าน</small>

ผมตรงไปที่ Daiso ซื้อหัวแร้งกับตะกั่วแล้วกลับบ้าน นั่นเป็นครั้งแรกที่ผมบัดกรี

## กล่องที่สอง📦 ตัดข้อสันนิษฐานทีละข้อกับ Claude

![หัวแร้งเสียบปลั๊กกำลังร้อน ข้าง ๆ มีตะกั่วและคีย์บอร์ด](/images/20261102-aula-f108-keyboard-repair/08-인두기-달구기.webp)
<small>เผาหัวแร้ง Daiso ที่เพิ่งใช้ครั้งแรก</small>

ผมเผาหัวแร้งให้ร้อนแล้วดูด้านหลังตำแหน่ง X ซ็อกเก็ตด้านหนึ่งยกขึ้นมานิดหน่อย ตอนนั้นคิดว่าแค่ตะกั่วลอย 💥**ที่จริงไม่ใช่ตะกั่ว แต่แพดทองแดงบนบอร์ดหลุดออกมาทั้งแผ่น** 🤯

![ซ็อกเก็ต X ยกขึ้นเล็กน้อยและยื่นออกจากบอร์ด](/images/20261102-aula-f108-keyboard-repair/09-튀어나온-소켓.webp)
<small>ซ็อกเก็ต hot-swap ของ X ที่ยื่นออกมา ตอนที่ยังไม่รู้ว่าแพดหลุด</small>

![ซ็อกเก็ต hot-swap สีดำที่หลุดออกมาวางบนฝ่ามือ](/images/20261102-aula-f108-keyboard-repair/10-떨어진-소켓.webp)
<small>ซ็อกเก็ต X ที่กำลังจะใส่กลับโดยไม่รู้อะไรเลย</small>

ผมบัดกรีซ็อกเก็ตกลับเข้าไปโดยไม่รู้อะไรเลย ซ็อกเก็ตเอามาจากตำแหน่ง F10 ที่ไม่ได้ใช้ พอซ่อมรอบแรกเสร็จ ก็คิดว่าทำได้ดีแล้ว 😎

![การบัดกรีครั้งแรก ละลายตะกั่วแล้วหยดลงตำแหน่งซ็อกเก็ต](/images/20261102-aula-f108-keyboard-repair/움짤1-첫-납땜.webp)
<small>วิธีที่ผิด: หยดแค่ตะกั่วที่ละลายโดยไม่ได้เผาบอร์ดให้ร้อนก่อน</small>

![ด้านหลังบอร์ดหลังบัดกรีครั้งแรก](/images/20261102-aula-f108-keyboard-repair/11-1차-수리.webp)
<small>การซ่อมรอบแรกที่ตอนนั้นคิดว่าทำได้ดีแล้ว</small>

ผลกลับแย่ลง X ยังกดไม่ติด และปุ่มที่ไม่เกี่ยวกันเริ่มกดติดพร้อมกันเป็นคู่ ๆ ผมกดทีละปุ่มในหน้าทดสอบคีย์บอร์ดและ Notepad แล้วสรุปได้แบบนี้

![กดปุ่มรอบ X บนคีย์บอร์ดที่ประกอบแล้ว Notepad ขึ้นตัวอักษรผิด](/images/20261102-aula-f108-keyboard-repair/움짤2-첫-결과-메모장.webp)
<small>Notepad หลังซ่อมรอบแรก ตอนกดปุ่มด้วยความหวังว่าจะใช้ได้เลย</small>

| ปุ่มที่กด | ผล |
|---|---|
| Ctrl หรือ Shift | กดติดพร้อมกันทั้งคู่ |
| Alt | ติดพร้อม Z |
| Spacebar | ติดพร้อม B |
| . | ติดพร้อม Fn |
| ↑ | ติดพร้อม ↓ |
| A·S·D·F·G | แต่ละปุ่มปกติ |
| C·V·N·M | แต่ละปุ่มปกติ |

จากตรงนี้ผมกับ Claude เริ่มคุยกันจริงจัง การวินิจฉัยแรกของ Claude คือ**ไลน์ช็อต** สองแถวติดกัน ทุกคู่คือปุ่มหนึ่งในแถว Shift กับปุ่มที่อยู่ใต้มันพอดีในแถว Ctrl 🤔

![รูปบอร์ดทั้งแผ่นที่วงคู่ปุ่มที่กดติดพร้อมกันด้วยวงสีส้มและเส้นสีแดง](/images/20261102-aula-f108-keyboard-repair/13-같이-눌리는-짝.webp)
<small>แผนที่คู่ปุ่มที่กดติดพร้อมกันบนด้านหลังบอร์ด ทุกคู่คือซ็อกเก็ตที่อยู่บนล่างติดกันพอดี</small>

แน่นอนว่าตั้งแต่แรกไม่ได้ดูชัดขนาดนี้ พอผมอัปโหลดรูปจุดที่หลุด บริเวณแพดทางซ้ายของ X เป็นสีน้ำตาล ไม่ใช่สีเงิน ลองขูดด้วยคัตเตอร์ก็ไม่เจออะไร แพดของปุ่มอื่นเป็นสีเงินหมด เลยแน่ใจว่าแพดหลุด 😮

![ด้านหลังตำแหน่ง X: บริเวณแพดสี่เหลี่ยมทางซ้ายว่างและเป็นสีน้ำตาล มีรอยไหม้รอบ ๆ](/images/20261102-aula-f108-keyboard-repair/12-뜯긴-패드-자리.webp)
<small>ตำแหน่ง X ที่เหลือแค่พื้นสีน้ำตาลเพราะแพดหลุด และรอยฟลักซ์ไหม้รอบ ๆ</small>

ที่ผมเรียกมาตลอดว่า "แผ่นเล็ก ๆ" ชื่อจริงคือแพดทองแดง เป็นแผ่นโลหะบาง ๆ ที่ยึดขาสวิตช์ และเพราะเป็นทองแดงที่พิมพ์อยู่บนบอร์ด จึงเอามาจากที่อื่นมาติดไม่ได้ ✔**<mark>ที่ย้ายมาได้มีแค่ซ็อกเก็ต ส่วนแพดที่หายไปต้องใช้สายไฟต่อแทน</mark>**

ไม่มีมัลติมิเตอร์ก็เหลือวิธีเดียว แก้จุดที่สงสัยทีละจุด กดใหม่ แล้วถ้าไม่เปลี่ยนก็ตัดทิ้ง Claude เสนอผู้ต้องสงสัย ผมลองจริงแล้วบอกผล นี่คือข้อสันนิษฐานที่ตัดทิ้งไปด้วยวิธีนั้น

| ข้อสันนิษฐาน | สิ่งที่ลองจริง | ผล |
|---|---|---|
| เสียเพราะเสียบไฟตอนยังร้อน | ถาม Claude ได้คำตอบว่าไฟต่ำ 5V แทบไม่มีทางทำให้ชิปเสียจากความร้อน | ตัดทิ้ง |
| เศษโลหะบนบอร์ด | คีบออกด้วยแหนบ | ไม่เปลี่ยน |
| รอยฟลักซ์ไหม้ | เช็ดออก | ไม่เปลี่ยน |
| วงสีเงินรอบรูคือตะกั่ว | Claude มองว่าเป็นตะกั่ว แต่ผมดูแล้วคือขาสวิตช์ | Claude พลาด ตัดทิ้ง |
| ก้อนตะกั่ว | แค่พอกสูงบนแพด ไม่ได้แตะเส้นข้าง ๆ | ไม่เกี่ยว |
| ขาสวิตช์ X แตะกันในรู | ถอดสวิตช์ X แล้วทดสอบ | ไม่เปลี่ยน |

Claude ก็พลาดเหมือนกัน ทั้งมองวงสีเงินเป็นตะกั่ว และตอนแรกอธิบายว่า "สองแถวทั้งแถวกลายเป็นเส้นเดียวกัน" พอผมถามกลับว่าในแถวนั้นยังมีหลายปุ่มที่กดได้ปกติไม่ใช่เหรอ มันก็แก้คำอธิบายทันที ถึงสองแถวจะติดกัน ก็จะพันกันแค่**คอลัมน์ที่มีปุ่มทั้งแถวบนและแถวล่าง** C·V·N·M ปกติเพราะแถวข้างล่างเป็น Spacebar เลยไม่มีคู่ 😮

![รูปบอร์ดที่วาดเส้นแถว Shift และเส้นแถว Ctrl มาบรรจบกันที่จุดเดียว](/images/20261102-aula-f108-keyboard-repair/14-두-줄-쇼트-원리.webp)
<small>ภาพวาดบนบอร์ดแสดงหลักการที่เส้นแถว Shift กับแถว Ctrl มาแตะกันที่จุดเดียว</small>

ผมเช็กคำอธิบายนี้ด้วยการค้นหาด้วย คีย์บอร์ดส่งสัญญาณไปทีละคอลัมน์แล้วอ่านแถว ถ้าสองแถวติดกัน ปุ่มบนล่างจะถูกอ่านพร้อมกัน ([เอกสาร QMK](https://develop-docs.qmk.fm/how_a_matrix_works)) และได้รู้ด้วยว่าดูจากอาการอย่างเดียวแยกไม่ออกว่าเป็นบอร์ดช็อตหรือชิปคอนโทรลเลอร์เสีย แต่เพราะจุดที่ผมทำงานอยู่ตรงกลางระหว่างสองแถวที่พันกันพอดี ผมเลยเดิมพันว่าเป็นที่บอร์ด 😎

## กล่องที่สาม📦 ไม้จิ้มฟันหนึ่งอันกับทางอ้อมไปแพดข้าง ๆ

ผมสงสัยว่าต้องไปซื้อมัลติมิเตอร์หรือเปล่า เลยให้ Claude คิดแบบที่ไม่ต้องซื้อ คำตอบคือใช้หน้าจอทดสอบคีย์บอร์ดเป็นเครื่องวัดเลย 🤩

![ภาพซูมบริเวณที่หลุด วงสีส้มคือโซนที่ต้องกดด้วยไม้จิ้มฟัน](/images/20261102-aula-f108-keyboard-repair/15-이쑤시개로-쇼트-찾기.webp)
<small>โซนที่ต้องกดแรง ๆ ด้วยไม้จิ้มฟันระหว่างกด Ctrl ค้างไว้</small>

ถ้ากด Ctrl ค้างไว้ Shift จะติดบนหน้าจอด้วย ในสภาพนั้นให้ใช้ไม้จิ้มฟันกดไปทั่วรอบจุดที่หลุด เพื่อหาจุดที่ Shift ดับ ไม้จิ้มฟันไม่นำไฟฟ้า เลยไม่ทำให้ผลเพี้ยน ผมกดไปเรื่อย ๆ จนได้ยินเสียง "แต๊ก" แล้ว Shift ก็เริ่มทำงานแยกกัน 🤯

ดูเหมือนปลายเส้นทองแดงที่ยกขึ้นไปแตะเส้นแถวข้างล่าง แล้วหลุดออกจากกัน 💥**<mark>ไม้จิ้มฟันอันเดียวจับไฟช็อตที่ตามองไม่เห็นได้</mark>**

เหลือ X ผมไม่รู้ว่าต้องต่อขาฝั่งที่แพดหลุดไปที่ไหน ตอนแรก Claude คิดว่าฝั่งปุ่ม S มีโอกาสมากกว่า เพราะคีย์บอร์ดส่วนใหญ่ใช้คอลัมน์ร่วมกันแบบเฉียงอย่าง Z-A-Q และ X-S-W ส่วนวิธีใช้มือแตะสายไฟเช็กก่อนบัดกรี ผมเอามาจากเคสซ่อมในคอมมูนิตี้คีย์บอร์ด ([เคส KeebTalk](https://www.keebtalk.com/t/need-help-fixing-lifted-pads-hotswap-socket/20075)) 🤔

![รูปรอบ X ที่วงจุดยึดและตัวเลือก ①–⑦ ไว้](/images/20261102-aula-f108-keyboard-repair/16-X-연결-후보.webp)
<small>ตัวเลือกเจ็ดจุดที่จะลองแตะสายไฟ โดยใช้แพดขวาของ X เป็นจุดยึด</small>

สายไฟผมดึงมาจากสาย LAN หนึ่งเส้นแล้วปอกปลายทั้งสองข้าง ตอนบัดกรีต่อครั้งแรก ทุกปุ่มใช้ได้ยกเว้น X ปรากฏว่าหลังติดซ็อกเก็ตแล้ว ต้องเสียบสวิตช์และกดค้างไว้ระหว่างแตะสายไฟ ขาทั้งสองของซ็อกเก็ตจะต่อกันก็ต่อเมื่อกดสวิตช์เท่านั้น 😫

![สายไฟเส้นเล็กที่ดึงจากสาย LAN และปอกแล้ว](/images/20261102-aula-f108-keyboard-repair/17-랜선-전선.webp)
<small>สายไฟหนึ่งเส้นจากสาย LAN ปอกปลายทั้งสองข้าง</small>

![บัดกรีสายไฟจากขาซ้ายของซ็อกเก็ต X ไปที่แพดข้าง ๆ](/images/20261102-aula-f108-keyboard-repair/움짤3-전선-납땜.webp)
<small>บัดกรีสายที่ต่อกับขาซ้ายของซ็อกเก็ตไปที่แพดบนบอร์ดข้าง ๆ</small>

พอเสียบสวิตช์แล้วแตะใหม่ ก็ได้คำตอบ แตะแพด D49 และ D48 ด้านบนแล้วขึ้น D แปลว่าขาฝั่งที่หลุดต่ออยู่กับเส้นเดียวกับ D อยู่แล้ว แล้วพอแตะแพด D63 ที่อยู่ข้าง ๆ พอดี X ก็ขึ้น ไม่ใช่ S ที่ Claude บอกว่าน่าจะใช่ที่สุด และไม่ใช่ D ตัวเลือกถัดไปด้วย 😮

![เส้นทางที่ต่อแพด D63 กับขาซ็อกเก็ต X วาดเป็นเส้นสีน้ำเงิน](/images/20261102-aula-f108-keyboard-repair/18-D63-연결.webp)
<small>เส้นทางสายไฟที่ต่อซ็อกเก็ต X กับแพด D63 ที่อยู่ข้าง ๆ พอดี</small>

สรุปคือการเชื่อมต่อที่เคยวิ่งไปบอร์ดด้านบน ถูกเบี่ยงไปที่แพดข้าง ๆ แทน ตอนไม่กดก็เงียบ พอกด X ขึ้นแค่ครั้งเดียวพอดี ✔**<mark>จุดที่ถูกต้องไม่ได้มาจากการเดา แต่มาจากการแตะสายไฟจริง ๆ</mark>**

![หน้าจอ Notepad บนโน้ตบุ๊กที่เช็กว่ากด X แล้วพิมพ์ได้](/images/20261102-aula-f108-keyboard-repair/19-메모장-테스트.webp)
<small>เช็กการพิมพ์ X ใน Notepad หลังซ่อม</small>

![เว็บทดสอบคีย์บอร์ดแสดงว่าปุ่ม X ถูกอ่านแล้ว](/images/20261102-aula-f108-keyboard-repair/움짤4-X-테스트-완료.webp)
<small>การพิมพ์ X ที่ยืนยันบนเว็บทดสอบคีย์บอร์ดหลังซ่อม</small>

ยังเหลือข้อจำกัดอยู่ข้อหนึ่ง กด X กับ C พร้อมกันไม่ได้ จริง ๆ แต่ละปุ่มต้องมีไดโอดของตัวเอง แต่ตอนนี้ X ยืมของ C อยู่ ใช้แชตทั่วไปไม่มีปัญหาเลย ผมเลยปล่อยไว้แล้วประกอบกลับ มองย้อนไปแล้ว ควรเอาซ็อกเก็ตจาก Pause แทน F10 😛

| สิ่งที่เหลือ | สถานะ |
|---|---|
| X กับ C พร้อมกัน | ไม่ได้ แก้ได้ด้วยการย้ายสายไปที่ขาไดโอดของ X เอง |
| F10 | ว่างเพราะเอาซ็อกเก็ตไปแล้ว ย้ายซ็อกเก็ตจาก Pause มาหรือตั้งค่าปุ่มใหม่ได้ |
| ซ็อกเก็ต X | อ่อนแอเพราะไม่มีแพดอยู่ข้างหนึ่ง เวลาถอดสวิตช์ต้องประคองซ็อกเก็ตจากด้านหลัง |

## จริง ๆ ยอมแพ้ไปก็ได้

พูดตรง ๆ ผมยอมแพ้กลางทางก็ได้ ตอนเกิดไฟช็อต และตอนที่คีบเศษโลหะออก เช็ดรอยไหม้ หรือแม้แต่ถอดสวิตช์แล้วก็ไม่มีอะไรเปลี่ยน แต่ทุกครั้งที่คุยกับ Claude ก็จะมีสิ่งใหม่ให้ลองอีกหนึ่งอย่าง และรู้สึกตลอดว่าน่าจะทำได้ 🤔

สิ่งที่ Claude ทำไม่ใช่การตอบให้ถูก มันฟังอาการ เสนอผู้ต้องสงสัย ตัดทิ้งตามผลที่ผมลอง และเสนอวิธีอื่นเมื่อติด พออัปโหลดรูป มันก็ทำเครื่องหมายบนรูปเลยว่าต้องดูตรงไหน ข้อสันนิษฐานผิดมีไม่น้อย แต่ตรวจแล้วก็ถูกตัดทิ้งทันที 💰**<mark>ถึงไม่มีใครรู้คำตอบ ถ้าตรวจข้อสันนิษฐานจริงทีละข้อแล้วตัดทิ้งไป ทางก็จะเปิดออก</mark>**

คนที่บัดกรีครั้งแรกช่วยแพดที่หลุดไว้ได้โดยไม่มีมัลติมิเตอร์ ทำให้รู้สึกว่ายุค AI ที่ทำสิ่งที่ทำไม่ได้ให้ทำได้นี่ดีจริง ๆ บางทีการซ่อมได้หรือไม่ อาจไม่ได้ขึ้นกับฝีมือมากเท่ากับว่ามีสิ่งต่อไปให้ลองอยู่เสมอหรือเปล่า? 😎
